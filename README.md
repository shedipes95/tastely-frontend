# Tastely — Next.js + Tailwind Recipe Explorer

Modern recipe app with **Next.js (App Router)** and **Tailwind CSS**.  
Search meals, browse categories, and view **full recipe details** (ingredients + instructions).  
Works online via a small API proxy.

## Features
- 🔎 Search meals (e.g. “pasta”)
- 🏷️ Category filters (Beef, Chicken, Dessert, Seafood)
- 📄 Recipe details page with ingredients & instructions
- 🌓 Light/Dark toggle-ready styling (Tailwind)
- ⚡ Fast, client-side fetching with robust error handling

## Tech Stack
- Next.js 14 (App Router) • React • TypeScript
- Tailwind CSS • next/image
- External API via a simple proxy (Express/Render/Railway)
